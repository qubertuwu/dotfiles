# 🌌 Dotfiles Qubert (Hyprland + Quickshell / Caelestia)

Полноценная конфигурация рабочего окружения **Hyprland** с кастомной оболочкой на базе **Quickshell** (`end4-pC`), живыми обоями Wallpaper Engine, экранным переводчиком, интеграцией ИИ, всеми горячими клавишами (с поддержкой EN и RU раскладок) и утилитами.

Поддерживает установку в **1 команду** на **Arch / CachyOS** и **Fedora Linux** как на основном ПК, так и на ноутбуке.

---

## ⚡ Быстрая установка на ноутбуке в 1 команду

На свежеустановленной системе откройте терминал и выполните:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/qubertuwu/dotfiles/main/install.sh)
```

### Либо ручная установка:
```bash
git clone https://github.com/qubertuwu/dotfiles.git ~/.dotfiles
cd ~/.dotfiles
./install.sh
```

## 🧩 Что входит в состав:

- **Оконный менеджер:** Hyprland (поддержка мультимониторов, адаптация под экраны ноутбуков, жесты тачпада 3 пальцами).
- **Оболочка / виджеты:** Quickshell (`end4-pC` / `caelestia`) — статусбар, быстрые переключатели, батарея, Wi-Fi, звук, уведомления.
- **Шеллы:** Fish и Bash с кастомным промптом Starship, автодополнением и алиасами.
- **Меню приложений:** Fuzzel (Material You цвета, интеграция с темой).
- **Терминалы:** Foot / Alacritty.
- **Экранный переводчик:** 
  - `Super + T` / `Super + Е` — карточный ввод и быстрый перевод Google.
  - `Super + Shift + T` / `Super + Shift + Е` — OCR распознавание текста с экрана (Tesseract RUS + ENG) и перевод поверх окон.
- **Живые обои:** Селектор обоев Wallpaper Engine / MPV (`Super + W`), автосинхронизация через systemd сервис.
- **Горячие клавиши:** Полная дубликация для английской и русской раскладок клавиатуры.
- **Редакторы:** VS Code (`settings.json`, список плагинов), Micro, Zed (`caelestia theme`).
- **Файловый менеджер:** Dolphin (с контекстным меню конвертации в PDF) и Thunar (с кастомными действиями).
- **Скриншоты:** Grim + Slurp + Swappy (`PrintScreen`).
- **Скрипты и системные утилиты:** `dolphin-to-pdf`, авторазблокировка очереди печати CUPS, скрипты шрифтов Roblox/Sober, btop, cava, fastfetch.

## ⌨️ Полная таблица горячих клавиш

> Все комбинации работают одинаково на **английской (EN)** и **русской (RU)** раскладках!

### 🚀 Запуск и приложения
| Комбинация (EN) | Раскладка RU | Действие |
|---|---|---|
| **Super + Q** / **Enter** | `Super + Й` / `Enter` | Запуск терминала (Foot / Kitty) |
| **Super + F** / **B** | `Super + А` / `Super + И` | Запуск браузера (Firefox) |
| **Super + E** | `Super + У` | Файловый менеджер (Dolphin / Thunar) |
| **Super + D** / **Super + Space** | `Super + В` / `Super + Пробел` | Меню приложений (Launcher / Fuzzel) |
| **Super + V** | `Super + М` | История буфера обмена (Cliphist) |
| **Super + .** (точка) | `Super + Ю` | Выбор эмодзи |
| **Super + I** / **Super + Esc** | `Super + Ш` / `Super + Esc` | Центр настроек оболочки (темы, анимации) |
| **Super + W** | `Super + Ц` | Селектор обоев (Wallpaper Engine / MPV) |
| **Super + M** | `Super + Ь` | Всплывающий медиаплеер |

### 🌐 Переводчик
| Комбинация (EN) | Раскладка RU | Действие |
|---|---|---|
| **Super + T** | `Super + Е` | Карточка быстрого перевода Google |
| **Super + Shift + T** | `Super + Shift + Е` | OCR-перевод выделенной области экрана поверх всех окон |

### 🪟 Управление окнами
| Комбинация (EN) | Раскладка RU | Действие |
|---|---|---|
| **Super + C** / **Alt + F4** | `Super + С` / `Alt + F4` | Закрыть активное окно |
| **Super + Shift + Q** | `Super + Shift + Й` | Принудительно убить зависшее окно |
| **Super + F11** / **Super + Alt + F** | `Super + Alt + А` | Полноэкранный режим (Fullscreen) |
| **Super + Alt + Space** | `Super + Alt + Пробел` | Плавающий режим окна (Floating) |
| **Super + P** | `Super + З` | Закрепить окно поверх всех (Pin) |
| **Super + Стрелки** | `Стрелки` | Переключить фокус между окнами |
| **Super + Shift + Стрелки** | `Shift + Стрелки` | Переместить окно |
| **Super + ЛКМ (зажать)** | — | Перетащить окно мышью |
| **Super + ПКМ (зажать)** | — | Изменить размер окна мышью |

### 📑 Рабочие столы (Workspaces)
| Комбинация | Действие |
|---|---|
| **Super + 1 .. 9** | Перейти на рабочий стол 1–9 |
| **Super + Shift + 1 .. 9** | Переместить окно на рабочий стол 1–9 |
| **Super + Tab** | Обзор всех столов и окон (Overview) |
| **Super + S** / `Super + Ы` | Скрытый карман (Special Workspace) |
| **Super + Shift + S** | Отправить окно в специальный карман |
| **Super + Колёсико мыши** | Листать рабочие столы |

### 💻 Особенности ноутбука (Laptop Features)
- **Тачпад:** свайп тремя пальцами горизонтально для переключения рабочих столов.
- **Яркость:** клавиши `Fn + Яркость` (`XF86MonBrightnessUp` / `Down`) поддерживаются автоматически через `brightnessctl`.
- **Громкость:** клавиши `Fn + Звук` (`XF86AudioRaiseVolume`, `XF86AudioLowerVolume`, `XF86AudioMute`).
- **Экран:** автоматическое обнаружение дисплеев ноутбука (`eDP-1`, `eDP-4`) и внешних мониторов (`DP-1`, `HDMI-A-1`).
- **Графика:** автоопределение NVIDIA / Intel / AMD (переменные NVIDIA активируются только при реальном наличии драйвера NVIDIA).

│   ├── illogical-impulse/  # Настройки внешнего вида, тем, шрифтов
│   ├── fuzzel/             # Стиль лаунчера приложений
│   ├── alacritty/          # Конфиг терминала Alacritty
│   ├── foot/               # Конфиг терминала Foot
│   ├── fish/               # Fish shell и приветствие Fastfetch

│   ├── btop/               # Системный монитор и темы

│   ├── micro/              # Текстовый редактор micro
│   ├── zed/                # Настройки редактора Zed
│   ├── Code/User/          # Настройки VS Code
│   ├── gtk-3.0/ & gtk-4.0/ # Темы Breeze-Dark, курсоры capitaine
│   ├── environment.d/      # Переменные окружения
│   ├── autostart/          # Автозапуск
│   ├── systemd/user/       # Пользовательские systemd юниты
