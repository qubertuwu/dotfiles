Hyprland & Quickshell — Горячие клавиши

Система CachyOS / Arch Linux | Двойная поддержка раскладок (EN / RU)
Клавиша Super = Win (⊞)
🚀 Основные и Приложения
Super + D В Поиск и меню программ (Launcher)
Super (быстро отпустить) Открыть меню приложений / обзор
Super + Q Й Терминал (Foot)
Super + F А Браузер (Firefox)
Super + E У Проводник файлов
Super + W Ц Выбор обоев (Wallpaper Engine) и тем
Super + M Ь Музыкальный плеер (управление треками)
Super + I или Super + Esc Панель настроек и пресетов тем
Super + T Е Переводчик (Google Translate на панели)
Super + Alt + C Редактор кода (VSCode)
Ctrl + Alt + V Настройки звука и громкости
🪟 Управление окнами
Super + C или Alt + F4 Закрыть окно (активное)
Super + V М Полноэкранный режим (Fullscreen)
Super + Alt + Пробел Плавающее окно / тайлинг
Super + Alt + F Развернуть окно с рамками
Super + P Закрепить поверх всех окон (Pin)
Super + ЛКМ (зажать) Перетаскивание окна мышью
Super + ПКМ (зажать) Изменение размера окна мышью
Super + ← → ↑ ↓ Переключить фокус на соседнее окно
Super + Shift + Стрелки Переместить окно в сторону стрелки
Alt + Tab Переключение между окнами
📸 Скриншоты и Запись экрана
Print Screen Снимок всего экрана (в папку Изображения)
Super + Shift + S Ы Снимок выделенной области (с заморозкой)
Super + Shift + Alt + S Быстрый снимок выбранного региона
Super + Shift + C Пипетка цвета (HEX цвет в буфер обмена)
Ctrl + Alt + R Запись экрана (видео)
Super + Alt + R Запись экрана с аудио
Super + Shift + Alt + R Запись области экрана
📋 Буфер, Панели и Система
Super + K Л История буфера обмена (Clipboard)
Super + . (точка) Выбор смайликов и эмодзи (Emoji)
Super + N Т Боковая панель (Уведомления и виджеты)
Ctrl + Alt + C Очистить все уведомления
Ctrl + Alt + Del Меню выключения / перезагрузки
Super + L Д Заблокировать экран (Lock screen)
Super + Shift + L Переход в спящий режим (Sleep)
Ctrl + Shift + Esc Диспетчер задач / Монитор системы
🖥️ Рабочие столы (Workspaces)
Super + 1 ... 0 Перейти на рабочий стол 1–10
Super + Shift + 1 ... 0 Перенести окно на рабочий стол 1–10
Super + Колесо мыши Переключение на след. / пред. стол
Super + S Ы Специальный скрытый стол (Scratchpad)
Super + Alt + S Спрятать окно в специальный стол
Ctrl + Super + Shift + ↓ Вернуть окно со специального стола
Подсказка: Зелёная метка Буква обозначает клавишу в русской раскладке ЙЦУКЕН.
